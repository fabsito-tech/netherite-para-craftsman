# Netherite para Craftsman

Complemento de comportamiento estilo Bedrock con recetas para conseguir netherite sin mesa de herrería. Incluye lingote y versiones de netherite de las herramientas y armadura.

## Recetas
- **1 diamante + 4 lingotes de oro → 1 lingote de netherite**
- **Herramienta/armadura de diamante + 1 lingote de netherite → su versión de netherite**

## Instalación
1. Descargá `Netherite-para-Craftsman.mcpack` desde la sección **Releases** (o usá el ZIP del repositorio).
2. Abrilo con Minecraft/Craftsman para importarlo.
3. En los ajustes del mundo, activá el paquete de comportamiento.
4. Probá las recetas en una mesa de crafteo.

## Compatibilidad
Está hecho como Behavior Pack de Minecraft Bedrock (mínimo declarado 1.20.0). Craftsman es una aplicación independiente y la importación de packs puede variar según la versión; no puedo garantizar que todas las ediciones de Craftsman acepten complementos Bedrock. Si no aparece la opción de importar o activar paquetes, esta versión del juego no admite este formato.
